# Al Zamin Technical Services — Website

Static site, no build step. Push this folder to a Git repo and serve it with any static host (GitHub Pages, Netlify, Vercel, cPanel).

- `index.html` — website
- `company-profile.html` — printable company profile (open in a browser, Print → Save as PDF, A4)
- `img/`, `brand/` — photos and logo (required by index.html)
- `docs/` — downloadable PDFs linked from the site

GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.
